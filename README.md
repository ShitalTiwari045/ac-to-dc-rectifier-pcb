# AC to DC Rectifier PCB

A simple AC to DC bridge rectifier PCB designed in KiCad.

## Features

- Full-wave bridge rectifier
- AC input terminal
- DC output terminal
- Smoothing capacitor
- Power indicator LED
- Single-layer PCB
- Compact PCB layout

## Components Used

- 4 × Diodes
- 2 × Resistors
- 1 × LED
- 1 × Electrolytic Capacitor
- Screw terminals for AC input and DC output

## Software

- KiCad 9
